# Portfólio — HTML, CSS e Python

Projeto inicial de portfólio profissional usando **HTML + CSS** na interface e **Python + Flask** no servidor.

## 1. Requisitos
- Python 3.10 ou superior
- VS Code (recomendado)



## 3. Criar e ativar o ambiente virtual (Windows)
No terminal do VS Code, execute:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Se o PowerShell bloquear a ativação, abra o terminal CMD e use:

```cmd
.venv\Scripts\activate.bat
```

## 4. Instalar o Flask

```bash
pip install -r requirements.txt
```

## 5. Executar o site

```bash
python app.py
```

## Por que Flask?
O HTML estrutura o conteúdo, o CSS cuida do visual responsivo e o Flask permite que o Python controle as rotas e envie dados para a página.
